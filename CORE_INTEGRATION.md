# اتصال به AS Academy Core

این ریپو فقط محتوای اختصاصی C++، مثال‌ها، تمرین‌ها، پروژه‌ها و قابلیت‌های اختصاصی Code Runner را نگهداری می‌کند.

منطق مشترک زیر باید از `AS-Academy-Core` تأمین شود و در این ریپو کپی نشود:
- Navigation و Drawer
- Design System و Theme
- Progress و Bookmark
- Quiz / Exercise engine
- Search
- Settings
- Room/Database
- Content Engine و Updater
- Course schema/contract
- Profile

قرارداد این دوره در `manifest.json` مطابق `course/template/manifest.json` در Core تعریف شده است.

Course ID: `cpp`
Minimum Core: `0.1.0`
Content schema: `1`
