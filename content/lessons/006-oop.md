# برنامه‌نویسی شی‌گرا

Class داده و رفتار مرتبط را در یک abstraction جمع می‌کند.

```cpp
class Account {
public:
    explicit Account(double balance) : balance_(balance) {}
    void deposit(double amount) { balance_ += amount; }
    double balance() const { return balance_; }
private:
    double balance_{};
};
```

## مفاهیم اصلی
- Encapsulation: پنهان‌کردن جزئیات پیاده‌سازی.
- Inheritance: ساخت نوع جدید بر پایه نوع موجود؛ فقط وقتی رابطه `is-a` واقعی است.
- Polymorphism: کار با interface مشترک و رفتار runtime متفاوت.
- Composition: اغلب از inheritance انعطاف‌پذیرتر است.

Destructor پایه polymorphic باید معمولاً `virtual` باشد.

## Rule of Zero
اگر resource را با typeهای RAII مدیریت کنید، اغلب نیازی به نوشتن destructor/copy/move سفارشی ندارید.
