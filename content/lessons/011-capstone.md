# پروژه نهایی — AS Store Manager

این پروژه برای اتصال همه مهارت‌های دوره طراحی شده است.

## فاز 1: Domain
Customer، Product، InventoryItem، Invoice و Payment را مدل کنید.

## فاز 2: Persistence
Repository interfaceها را تعریف و SQLite adapter پیاده‌سازی کنید. عملیات مالی چندمرحله‌ای باید transaction داشته باشد.

## فاز 3: Application Services
use caseهایی مثل CreateInvoice، ReceivePayment، AdjustInventory و GenerateReport را بسازید.

## فاز 4: UI
با Qt صفحات مشتری، کالا، فاکتور و گزارش را پیاده‌سازی کنید.

## فاز 5: Quality
unit test، integration test، backup/restore، error handling و Release packaging.

## Definition of Done
داده پایدار، build تکرارپذیر، مدیریت خطا، تست قواعد اصلی و معماری قابل توضیح.
