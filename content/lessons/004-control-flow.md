# کنترل جریان

## شرط
```cpp
if (score >= 10) {
    std::cout << "pass";
} else {
    std::cout << "fail";
}
```

## switch
برای انتخاب میان حالت‌های discrete مناسب است. فراموش‌کردن `break` می‌تواند باعث fallthrough شود؛ در صورت عمدی بودن بهتر است آن را واضح بیان کنید.

## حلقه‌ها
- `for`: وقتی iteration ساختار مشخصی دارد.
- range-based for: برای پیمایش containerها.
- `while`: وقتی شرط پایان مهم‌تر از شمارنده است.
- `do-while`: بدنه حداقل یک بار اجرا می‌شود.

## خطای رایج
حلقه بی‌نهایت، off-by-one و تغییر container هنگام iteration بدون درک invalidation از خطاهای متداول‌اند.

## تمرین
از 1 تا 100 اعداد بخش‌پذیر بر 3 را چاپ کنید و مجموع آن‌ها را نیز محاسبه کنید.
