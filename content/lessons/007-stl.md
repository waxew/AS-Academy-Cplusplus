# STL

STL مجموعه‌ای از container، iterator و algorithm است که طراحی generic C++ را نشان می‌دهد.

## انتخاب container
- `std::vector`: انتخاب پیش‌فرض برای توالی پویا.
- `std::array`: اندازه ثابت در compile time.
- `std::map`: کلید مرتب با جستجوی logarithmic.
- `std::unordered_map`: lookup میانگین constant-time با hash.
- `std::set`: مجموعه کلیدهای یکتا.

## Algorithms
به جای نوشتن loopهای تکراری، از `std::sort`, `std::find_if`, `std::transform`, `std::accumulate` استفاده کنید.

```cpp
std::sort(values.begin(), values.end());
```

## Lambda
Lambda رفتار کوچک را نزدیک محل استفاده تعریف می‌کند و برای algorithmها بسیار مفید است.

## تمرین
لیست دانشجوها را ابتدا بر اساس نمره نزولی و در حالت مساوی بر اساس نام مرتب کنید.
