# C++ چیست؟

C++ یک زبان برنامه‌نویسی کامپایل‌شونده، چندپارادایمی و دارای کنترل سطح پایین روی حافظه و منابع است. از آن در موتورهای بازی، سیستم‌های عامل، مرورگرها، نرم‌افزارهای مالی کم‌تاخیر، ابزارهای مهندسی، Embedded و برنامه‌های دسکتاپ استفاده می‌شود.

## مدل اجرا
کد منبع معمولاً این مسیر را طی می‌کند:
`Source -> Preprocessor -> Compiler -> Object Files -> Linker -> Executable`

این تفاوت مهمی با زبان‌هایی دارد که عمدتاً در runtime تفسیر یا JIT می‌شوند.

## چرا C++؟
- performance بالا و predictable
- کنترل ownership و lifetime
- zero-cost abstractions
- کتابخانه استاندارد غنی
- امکان برنامه‌نویسی procedural، object-oriented و generic

## هزینه این قدرت
خطاهایی مثل dangling pointer، data race و undefined behavior در صورت طراحی ضعیف ممکن‌اند. به همین دلیل در این دوره از ابتدا RAII، ابزارهای تشخیص خطا و شیوه‌های Modern C++ جدی گرفته می‌شوند.

## تمرین
سه نرم‌افزار یا سامانه پیدا کنید که C++ برای آن‌ها انتخاب مناسبی است و برای هرکدام دلیل فنی بنویسید.
