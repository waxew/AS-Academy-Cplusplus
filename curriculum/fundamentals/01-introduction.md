# 01 — معرفی C++

C++ یک زبان کامپایل‌شونده، چندپارادایمی و مناسب برای نرم‌افزارهایی است که کنترل منابع و کارایی اهمیت دارد.

## یاد می‌گیریم
- تفاوت Source، Compiler، Linker و Executable
- کاربردهای C++ در Desktop، Game، Embedded، System و Performance-Critical Software
- تفاوت کلی C++ با زبان‌های managed

## تمرین
سه کاربرد واقعی C++ بنویسید و برای هرکدام دلیل انتخاب زبان را توضیح دهید.
