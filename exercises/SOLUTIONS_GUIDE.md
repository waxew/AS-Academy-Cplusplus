# راهنمای پاسخ تمرین‌ها

پاسخ واحد اجباری نیست؛ ارزیابی بر اساس correctness، readability، ownership صحیح، error handling و complexity انجام می‌شود.

Checklist:
- warningهای Compiler بررسی شده‌اند؟
- resourceها leak ندارند؟
- ورودی نامعتبر مدیریت شده؟
- functionها مسئولیت مشخص دارند؟
- container مناسب انتخاب شده؟
- برای الگوریتم، complexity قابل توضیح است؟
