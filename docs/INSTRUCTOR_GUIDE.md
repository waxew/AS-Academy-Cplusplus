# راهنمای مدرس

هر درس با الگوی زیر ارائه شود:
1. هدف درس
2. پیش‌نیاز
3. توضیح مفهومی
4. مثال کوچک
5. خطاهای رایج
6. تمرین هدایت‌شده
7. تمرین مستقل
8. Quiz
9. پروژه کوچک در پایان فصل

برای دانشجوی صفر مطلق، اصطلاحات قبل از استفاده تعریف شوند. در بخش‌های pointer، lifetime، concurrency و UB از نمودار حافظه و مثال خطا استفاده شود.
