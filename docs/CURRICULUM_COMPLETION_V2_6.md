# C++ Curriculum Completion v2.6

The app-renderable curriculum now contains 90 comprehensive lessons. Together with the original 127-unit curriculum map, exercises, quizzes, specialist labs and capstone, these lessons cover the intended path from fundamentals through specialist C++.

Coverage includes language fundamentals, OOP, STL, data structures and algorithms, memory/lifetime, Modern C++20/23, templates/concepts/ranges/coroutines, concurrency, networking, databases, Qt, system/embedded/game programming, CMake/tooling, testing/debugging, performance, security, architecture and design patterns.

The remaining 127-unit map is retained as the granular curriculum reference. The 90 comprehensive app lessons intentionally aggregate closely related micro-topics to avoid artificial fragmentation while retaining instructional coverage.

Completion criteria for content: explanation + examples where applicable + warnings/tips + exercises/projects + assessments and capstone. Device QA and signed release distribution are operational/release concerns rather than curriculum gaps.
