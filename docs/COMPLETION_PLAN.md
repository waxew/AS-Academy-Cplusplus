# C++ Academy Completion Plan — v2.3.0

## وضعیت

ساختار سرفصل‌ها کامل است. تمرکز این فاز روی تبدیل دوره به تجربه آموزشی قابل ارزیابی و پروژه‌محور است.

## تکمیل‌شده در این فاز

- ارزیابی جامع پایان دوره
- Capstone کامل AS Store Manager
- Lab تخصصی Networking
- Lab تخصصی SQLite
- Lab تخصصی Qt
- Lab تخصصی Performance
- معیارهای قبولی و تحویل پروژه

## Definition of Done آموزشی

هر مسیر باید توضیح، مثال، تمرین، ارزیابی و پروژه مرتبط داشته باشد. Shared UX و Progress/Quiz/Exercise در AS-Academy-Core باقی می‌ماند و این ریپو فقط محتوای C++ را نگه می‌دارد.

## باقیمانده واقعی

- افزایش عمق متن و مثال برای تمام micro-lessonهای 127گانه داخل app package
- آزمون مستقل برای درس‌های بیشتر
- diagram/image assets
- Code Runner واقعی C++؛ تا زمان sandbox امن capability خاموش می‌ماند
- QA دستگاه و امضای Publish
