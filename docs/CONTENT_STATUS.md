# وضعیت محتوای دوره

## نسخه 1.2.0
- 107 Micro-Lesson در مسیر پیوسته صفر تا پروژه نهایی
- 6 Level استاندارد
- 10 Chapter metadata
- 11 درس مادر برای توضیح عمیق‌تر
- Quizهای ساختاریافته
- Structured Exercises
- مثال‌های C++ قابل Build
- پروژه‌های مرحله‌ای و Capstone

## باقی‌مانده برای غنای محتوایی بیشتر
- افزایش تعداد سؤال‌های Quiz برای هر Micro-Lesson
- اضافه‌کردن diagram/asset تصویری
- افزودن code challenge خودکار برای همه درس‌ها
- توسعه پروژه‌های تخصصی اختیاری Qt/Boost/SQLite به targetهای dependency-aware

از این نسخه، مسیر اصلی آموزش از صفر تا سطح تخصصی دارای 107 واحد آموزشی مشخص است.
