# وضعیت محتوای دوره

نسخه 1.1.0 اولین بسته محتوای ساختاریافته را اضافه می‌کند.

## موجود
- 6 Level استاندارد
- 10 Chapter
- 11 Lesson متنی اصلی
- 3 Quiz ساختاریافته
- بانک Exercise ساختاریافته
- مثال‌های C++ قابل Build
- پروژه‌های مرحله‌ای
- Capstone specification

## مرحله توسعه بعدی
هر Lesson اصلی باید به چند micro-lesson شکسته شود تا کل سرفصل صفر تا تخصصی به حدود 100+ درس کوتاه تبدیل شود. همچنین Quiz هر Chapter، code challenge و assetهای diagram باید گسترش یابد.

این فایل برای شفافیت وضعیت است؛ وجود Course Map به‌تنهایی به معنی نگارش کامل تک‌تک درس‌ها نیست.
