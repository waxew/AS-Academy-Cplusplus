# واژه‌نامه C++

- Compiler: تبدیل Source Code به کد ماشین/آبجکت.
- Linker: اتصال Object Fileها و Libraryها.
- Translation Unit: فایل source پس از preprocessing.
- Scope: محدوده اعتبار نام‌ها.
- Lifetime: بازه زمانی زنده‌بودن یک object.
- RAII: اتصال مالکیت resource به lifetime شیء.
- UB: Undefined Behavior؛ رفتاری که استاندارد نتیجه آن را تعریف نکرده است.
- STL: مجموعه container، iterator و algorithmهای استاندارد.
- Template: مکانیزم generic programming.
- Move Semantics: انتقال resource به جای copy پرهزینه.
- ABI: قرارداد باینری میان اجزای کامپایل‌شده.
