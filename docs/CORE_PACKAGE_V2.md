# Core-compatible Course Package v2

نسخه 2.0 دوره C++ اکنون یک بسته مستقیم برای `AssetCoursePackageLoader` در AS-Academy-Core دارد.

مسیر قابل کپی به assets برنامه:

`course/cpp/`

ساختار شامل manifest، levels، chapters، lesson JSON، exercises، quizzes، projects و glossary است.

این ساختار عمداً از منطق مشترک UI/Progress/Search/Quiz در Core استفاده می‌کند و آن منطق را در ریپوی C++ تکرار نمی‌کند.
